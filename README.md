# OpenGl in Rust

## Objectives
Objectives I set to do in this project
- install rust  
- prepare OpenGl wrapper
- create a window
- make a triangle  
- shaders
- rotate triangle
- textures
- 3d models and rotations

- implement a general draw function
- make cube and rotate it
- create a .obj file reader
- make .obj appear in screen
- make camera movements
